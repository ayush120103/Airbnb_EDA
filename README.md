# 🏠 Airbnb Exploratory Data Analysis (EDA)

## 📝 Project Overview

This project focuses on performing an in-depth **Exploratory Data Analysis (EDA)** on Airbnb listing data to uncover meaningful insights related to pricing, availability, room types, and neighborhood-level performance. The objective is to understand the key factors that influence Airbnb rental prices and demand, and to translate raw data into actionable business insights.

The project simulates a real-world data analytics use case and demonstrates practical skills in **data cleaning, univariate and multivariate analysis, data visualization, and insight generation** using Python.

---

## 🎯 Business Objectives

The primary goals of this analysis are:

* To understand how **pricing varies across neighborhoods and room types**
* To analyze **availability and demand patterns** for Airbnb listings
* To identify **key factors influencing rental prices**
* To explore host and listing characteristics that impact performance
* To provide insights that could help **hosts optimize pricing** and **customers make informed booking decisions**

---

## 🗂️ Dataset Description

The dataset used in this project is a public Airbnb dataset containing detailed information about listings in a city.

### Key Features Include:

* **Listing Information:** Listing ID, name, host ID
* **Location Data:** Neighborhood, latitude, longitude
* **Property Details:** Room type (Entire home/Private room/Shared room)
* **Pricing Metrics:** Price per night
* **Availability Metrics:** Availability over 365 days
* **Engagement Metrics:** Number of reviews, reviews per month

> ⚠️ This dataset is used strictly for educational and portfolio purposes and does not represent real Airbnb internal data.

---

## 📊 Exploratory Data Analysis Performed

The EDA includes:

* **Univariate Analysis:** Distribution of prices, availability, and reviews
* **Bivariate Analysis:** Relationship between price and room type, neighborhood, availability
* **Multivariate Analysis:** Combined impact of location, room type, and reviews on pricing
* **Visual Analysis:** Box plots, histograms, bar charts, and heatmaps

---

## 📈 Key Insights

Some important insights derived from the analysis include:

* Entire homes/apartments generally have **higher prices** compared to private and shared rooms
* Significant **price variation exists across neighborhoods**, indicating location as a major pricing driver
* Listings with higher review counts often show **better demand and occupancy**
* High availability does not always correlate with higher pricing or revenue

These insights can help stakeholders better understand market dynamics and pricing strategies.
